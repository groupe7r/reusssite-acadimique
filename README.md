# Student Success Prediction

This project is a machine learning application for predicting academic success from student data. It follows the idea presented in `rapport_pfe_ameliore.docx`: educational data can be used to identify important factors such as previous grades, absences, study time, and age, then estimate whether a student is likely to succeed or fail.

The project trains several classification models with scikit-learn and exposes them through a Streamlit interface where the user can enter student information and receive a prediction with a probability.

## Project Overview

The prediction problem is binary:

- `1`: success
- `0`: failure

The current implementation uses four input features:

- `age`: student age
- `absences`: number of absences
- `g1`: first semester grade
- `study_hours`: study hours

The main models used are:

- Logistic Regression
- Decision Tree
- Random Forest
- Calibrated Decision Tree
- Calibrated Random Forest

## Main Files

- `main.py`: trains and evaluates the machine learning models.
- `app.py`: Streamlit web interface for prediction.
- `student-por.csv`: dataset used by the current training script.
- `student_models.pkl`: saved trained models generated by `main.py`.
- `imputer.pkl`: saved missing-value imputer generated by `main.py`.
- `newbasedone.py`: dataset cleaning/transformation script used for experimentation.

## Installation

Create a virtual environment:

```powershell
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required packages:

```powershell
python -m pip install -r requirements.txt
```

## Train The Models

Run the training script:

```powershell
python main.py
```

This script:

1. Loads `student-por.csv`.
2. Converts the target column `reussite` from `yes/no` to `1/0`.
3. Removes duplicated rows.
4. Renames columns:
   - `note de smestre1` to `g1`
   - `heures-etudie` to `study_hours`
5. Selects the four features: `age`, `absences`, `g1`, `study_hours`.
6. Handles missing values with `SimpleImputer`.
7. Splits the data into train and test sets.
8. Trains and evaluates the models.
9. Saves the generated files:
   - `student_models.pkl`
   - `imputer.pkl`

These `.pkl` files are required by the Streamlit app.

## Run The Streamlit App

After installing the requirements and generating the `.pkl` files, run:

```powershell
streamlit run app.py
```

The app will open in the browser. You can choose a model, enter the student information, and click the analysis button to display the predicted result and success/failure probability.

## Notes

- If `student_models.pkl` or `imputer.pkl` are missing, run `python main.py` first.
